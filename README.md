##1. 单例模式 + __call__魔法方法：全局配置管理器 & 输入安全校验器
本项目为 Python 面向对象进阶实战案例，独立手写实现 **全局配置单例管理器** 与 **用户输入安全校验器**。
摆脱传统零基础玩具代码，结合后端真实工程思维、安全编码思维落地练习，巩固核心魔法方法与单例设计模式。

## 项目文件
- config_manager.py   # 核心类文件（单例配置类、安全校验器类）
- config_main.py      # 程序入口 & 多场景测试用例

## 学习知识点
### 课程基础核心知识点
1. `__new__` 魔法方法：负责对象创建，执行优先级高于 `__init__`
2. `__init__` 魔法方法：实例初始化，为对象绑定属性数据
3. `__str__` 魔法方法：自定义对象打印输出格式
4. `__call__` 魔法方法：让类实例支持**函数式直接调用**

### 实战拓展知识点（视频未讲解｜工程加分项）
1. **单例模式**：全局仅生成唯一实例，统一管理项目配置，避免资源重复创建、配置混乱
2. **数据脱敏处理**：对 API 密钥、数据库密码等敏感信息隐藏展示，防止日志信息泄露
3. **用户输入校验机制**：拦截空输入、非法空白输入
4. **简易 SQL 注入风险检测**：通过正则匹配高危关键字，模拟后端接口安全过滤逻辑
5. **模块化工程思想**：类定义与测试代码分离，符合真实项目开发规范

## 运行环境
- Python 3.8 及以上版本

## 功能说明
### 1. 全局配置管理器（ConfigManager）
- 通过 `__new__` 实现标准单例模式，多次实例化仍为同一个对象
- 新增初始化锁，避免重复加载、覆盖配置
- 重写 `__str__` 方法，自动脱敏敏感隐私配置
- 适用于后端项目全局数据库、密钥、系统参数统一管理

### 2. 输入安全校验器（InputValidator）
- 依托 `__call__` 魔法方法，实现简洁优雅的调用方式
- 内置两层校验逻辑：空值拦截、SQL 高危语句拦截
- 支持安全检测开关，可灵活开启/关闭校验功能
- 可直接复用在 Flask 接口、AI 问答输入、用户参数校验场景

##2. 多态 / 类方法 / 静态方法：后台任务调度系统
 **文件：** `poly_practice.py`
 **知识点：** 多态、`@classmethod`工厂方法、`@staticmethod`工具方法
 ### 设计思路
 模拟后端任务调度场景，使用父类 `BaseTask` 定义统一的任务执行接口 `run()`。
 创建3个任务子类（数据导出、日志清理、数据库备份），各自重写 `run()` 实现专属业务逻辑。
 - 类方法 `create_task`：作为任务工厂，传入任务类型字符串，自动生成对应的任务实例，外部调用者不需要手动实例化各个子类，解耦代码。
 - 静态方法 `check_task_id`：纯工具校验函数，不需要实例对象，直接通过类调用，用于校验任务ID格式合法性。
 ### 核心亮点
 (1). **多态**：循环遍历任务列表，统一调用 `run()`。调度代码不用判断任务类型，Python自动执行对应子类的业务逻辑。后续新增任务，只需要新增子类，调度循环代码完全不用修改，符合工程开闭原则。
 (2). **工厂类方法**：封装对象创建逻辑，集中管理任务的实例化。
 (3). **静态工具方法**：职责单一，只做参数校验，不依赖类或者实例的属性。
