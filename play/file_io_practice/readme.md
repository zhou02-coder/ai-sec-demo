# 文件IO实战：简易日志工具 file_demo.py
## 项目介绍 Introduction
模拟后端开发中的日志记录组件，实现日志追加写入、逐行读取、文件指针操作。
采用工业标准 `with open` 上下文管理器，增加异常捕获，规避文件乱码、权限、文件不存在等线上常见问题。

## 知识点覆盖 Covered Knowledge
1. 文件打开模式 r / a，utf-8编码设置
2. with 上下文管理器自动关闭文件
3. readline() 流式逐行读取（适合大文件）
4. tell() 获取文件指针位置，seek()移动文件指针
5. 基础异常捕获：FileNotFoundError / PermissionError
6. os模块：获取当前目录、文件存在判断、遍历目录文件

> ⚠️ 实战重点坑点：seek 的偏移单位是**字节**，不是字符。UTF-8中文单个汉字占用3字节，从汉字中间切割会出现解码乱码。

## 项目特性 Features
1. 追加模式 a：持续写入日志，不会覆盖历史记录
2. 防御性编程：捕获常见文件异常，程序不会直接崩溃
3. 流式读取：大文件不会一次性全部加载进内存，节省内存开销
4. 跨平台编码：强制指定 utf-8，解决 Windows 中文乱码问题
